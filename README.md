# Grand_strategy

Прототип 2D-карты из файлов Hearts of Iron IV.
Режим: **Политическая карта (1936.01.01)** + Однотонная.
Границы: Побережье, Страны, Регионы, Провинции.

## Команды

**Генерация данных и карт из файлов игры (Python):**
```cmd
python converter.py "D:\games\Hearts of Iron IV (2016)\Hearts of Iron IV"
```

**Запуск проекта (Godot):**
```cmd
..\Godot_v4.7.2-stable_win64.exe --path .
```
*(укажите правильный путь к вашему godot.exe, если он другой)*

## Управление
- **WASD / Стрелки** — перемещение.
- **Колесико мыши** — плавный зум.
- **Левый клик** — выбор провинции.
- **F11** — полноэкранный режим.
- **Shift** — ускорение перемещения.
- **Мышь у края окна** — прокрутка карты.

Скрипт читает `definition.csv`, `history/states/*.txt`, `provinces.bmp` и конфигурации стран, генерируя:
- `map_political.png` (заливка политической картой стран)
- `map_flat.png` (однотонная заливка суши)
- `borders_coast.png` (береговая линия)
- `borders_country.png` (государственные границы)
- `borders_state.png` (границы регионов)
- `borders_province.png` (границы провинций)
- `province_id.png` (точная карта ID провинций, зашифрованная в RGB для чтения по клику)
- `data.json` (информация по каждой провинции)
- `metadata.json` (версия игры и дата закладки)
- `colors.json` (таблица тегов и их RGB цветов)

## Открытие в Godot
Для запуска в Godot:
```cmd
..\Godot_v4.7.2-stable_win64.exe --path .
```
Внутри проекта доступна сцена `Main.tscn` со слоями, переключателями (Политическая/Однотонная) и полной логикой камеры (перемещение WASD, краю экрана, плавный зум). 

По клику левой кнопкой мыши высвечивается точный ID провинции (читается напрямую из province_id.png), а сама провинция подсвечивается шейдером на GPU.

## Текущие ограничения
1. Векторизация и создание полигонов (SVG) отложены в пользу отладки геометрии и политической карты.
2. Игнорируются слоты логики (например, `IF { ... }`) внутри файлов истории, если они меняют владельцев сложными путями (в консоль выводятся предупреждения). Владельцы на стартовую дату рассчитываются через `owner = TAG`.
3. Карта не зациклена по горизонтали визуально в камере.
